kin77dan Tools

私個人が日常的に欲しいと思ったWebツール（時計・関数電卓・電子工作計算・デバイス動作確認など）を適当にまとめた個人ツール集です。すべてブラウザ内のみで動作します。

時計

日常

デジタル/アナログ切替・全画面・世界時計・カスタム音楽アラーム（バックグラウンド対応）。

電卓（シンプル / 関数 / 多機能）

計算

通常電卓から微積分・方程式・分数入力・変数代入まで切り替え可能な計算機。

ストップウォッチ

計測

1/100秒単位の計測とラップタイム記録に対応。

BPM測定

音楽

Spaceキーやタップ間隔からリアルタイムに曲のBPMを計測。

2・8・10・16進数変換

開発・工作

いずれか1つに入力すると他の進数へ即座に相互変換。0〜15の早見表付き。

LED抵抗計算

電子工作

電源電圧・順方向電圧・目標電流から必要な抵抗値とE24系列目安・消費電力を算出。

RCフィルター計算

電子工作

抵抗(R)・容量(C)・カットオフ周波数(fc)のうち2つを入力して残りを自動計算。

複数動画同時再生

メディア

複数のローカル動画ファイルを並べて同時再生・先頭同期・コマ送り比較。

周波数ジェネレーター

オーディオ

任意の周波数・波形を複数音同時に発振。ドレミ音階やテスト周波数プリセット搭載。

キーボード・マウス確認

デバイス確認

ビジュアル図で押下済みキーやマウスボタンの色保持確認・ポーリングレート計測。

コントローラー確認

デバイス確認

DualSense対応の視覚ボタン確認・L2/R2トリガーメーター・スティック軌道とドリフト診断。

端末スペック

システム

アクセス中のPC・スマホのCPUコア数・GPU・画面解像度・バッテリー等を一覧表示。

ハッシュ値計算・比較

検証・開発

MD5 / SHA-1 / SHA-256 / SHA-512 / SHA-3 / CRC32 に対応。複数ファイルのD&D比較・一致ハイライト付き。

文字数カウント

文章作成

総文字数・空白除外・行数・単語数・UTF-8バイト数・原稿用紙枚数をリアルタイム計測。

1次元・2次元コード生成

生成ツール

QRコード・ISBN・郵便バーコード・DataMatrix・Aztec・PDF417等に対応。全規格一括表示も可能。

1次元・2次元コード読取

読取ツール

カメラや画像ファイル（D&D・貼り付け対応）からQRコードや各種バーコードを読み取り。

カラーコード変換

デザイン・開発

HEX・RGB・HSL・HSV・CMYKをリアルタイム相互変換。透明度調整・WCAGコントラスト比判定付き。

文字化け相互変換

テキスト

UTF-8・Shift_JIS・EUC-JP・JIS等の誤解釈による文字化けの復元・意図的な文字化け変換＆総当たり候補表示。

YouTubeサムネ取得

メディア

YouTube動画のURLやIDから最高画質（1280×720）を含む全サイズのサムネイル画像を取得・保存。

ルーレット

ユーティリティ

自由な項目で抽選できる回転ルーレット。当選項目の除外・効果音・抽選履歴に対応。

音声スペクトル表示

オーディオ

音声ファイルやマイク入力の周波数スペクトル・波形・スペクトログラムをリアルタイムに可視化。

画像変換・圧縮・リサイズ

画像処理

PNG/JPEG/WebP形式変換・品質圧縮・リサイズ・回転反転。ブラウザ内処理でEXIF情報も自動削除。

モニター・Hz確認

デバイス確認

実測リフレッシュレート (Hz) 計測・全画面単色ドット抜け確認・階調/残像テスト。

テキスト差分比較 (Diff)

検証・開発

2つの文章やコードを行単位で比較し、追加・削除された箇所を色分け表示。

パスワード・乱数生成

セキュリティ

暗号論的乱数による安全なパスワード・UUID v4・16進トークンを一括生成。強度(bit)表示付き。

単位変換

計算

データ容量 (GB/GiB)・通信速度 (Mbps/MB/s)・長さ・重さ・温度をリアルタイム一括変換。

条件に一致するツールが見つかりませんでした。
